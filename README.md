Laboratório de Front-end 🎨
Descrição Detalhada:
Este repositório serve como meu laboratório de experimentação e aprendizado em desenvolvimento web. Aqui, documento minha jornada desde os fundamentos do HTML5 e CSS3, passando pela lógica dinâmica com JavaScript, até a construção de interfaces complexas com React. O objetivo é consolidar práticas de design responsivo, componentização eficiente e a criação de experiências de usuário (UX) fluidas. Cada pasta contém estudos isolados que refletem o domínio das tecnologias, desde a manipulação do DOM até a integração com APIs externas.

🛠️ Stacks e Tecnologias
Fundamentos: HTML5, CSS3, JavaScript (ES6+).

Frameworks: React.js, Vite.

Estilização: Responsividade e boas práticas de layout.

📂 Estrutura dos Projetos
/html-css: Projetos focados em estrutura e estilização.

/js-projects: Aplicações com lógica dinâmica e manipulação de DOM.

/react-apps: Aplicações componentizadas e interativas.
